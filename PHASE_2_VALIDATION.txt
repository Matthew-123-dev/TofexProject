CHECKOUT FLOW (State Diagram)
================================================================================

BROWSING
  └─ (User taps "Checkout" on carts)
  └─ Fulfillment created, stage=COLLECTING_DETAILS, checkout_step="choice"
  
COLLECTING_DETAILS (step="choice")
  ├─ M1: "Delivery or Pickup?"
  ├─ Delivery → step="street" (collect address)
  │   └─ M2: "Enter street address"
  │   └─ step="area"
  │       └─ M3: "Choose delivery area" (paginated, 8 per page + More + Other)
  │       ├─ Known area → save fee, step="pin"
  │       └─ Other area → step="other_area"
  │           └─ M3B: "What area?"
  │           └─ step="pin"
  │   └─ step="pin"
  │       └─ M4: "Share location (optional)"
  │       └─ step="landmark"
  │   └─ step="landmark"
  │       └─ M5: "Landmarks nearby?"
  │       └─ step="phone2"
  │   └─ step="phone2"
  │       └─ M6: "Alternate phone? (optional)"
  │       └─ step="notes"
  │   └─ step="notes"
  │       └─ M7: "Delivery notes? (optional)"
  │       └─ step="summary"
  │   └─ step="summary"
  │       └─ M8: "Confirm address + fee + total" [Confirm] [Edit]
  │       ├─ Edit → reset to step="street"
  │       └─ Confirm →
  │           ├─ Known area: fee set, stage=AWAITING_PAYMENT
  │           └─ Other area: stage=AWAITING_FEE_QUOTE
  │
  └─ Pickup → stage=AWAITING_PAYMENT (skip address)
      └─ M9_PICKUP: "Outlet address" (no fee)
  
AWAITING_FEE_QUOTE
  └─ M8B: "Getting quote..." (staff will quote via API/dashboard)
  └─ Staff sends M8C: "Fee is ₦X for 30 min delivery" [Accept] [Cancel]
  └─ stage=AWAITING_FEE_ACCEPT
  
AWAITING_FEE_ACCEPT
  ├─ [Accept] → stage=AWAITING_PAYMENT, batch.delivery_fee set
  └─ [Cancel] → stage=CANCELLED
  
AWAITING_PAYMENT
  ├─ M9/M9_PICKUP sent with bank details
  ├─ Customer uploads receipt photo → stage=AWAITING_APPROVAL
  ├─ Customer replies "ADDRESS" → Begin address re-edit (keep area, edit details)
  │   └─ Re-edit same 7 steps (street → landmark → phone2 → notes → summary)
  │   └─ stage back to AWAITING_PAYMENT when confirmed
  └─ (Auto-timeout: checkout_cancel_minutes) → stage=CANCELLED
  
AWAITING_APPROVAL
  ├─ M10: "Receipt received, confirming payment..."
  ├─ Staff reviews in dashboard
  ├─ (Receipt re-edit also available with "ADDRESS" reply)
  └─ Staff approves → stage transitions to Phase 3 (preparing/ready/dispatch etc.)

CANCELLED (from any stage)
  └─ M: "Order cancelled. Send *menu* to start again."
